# Reference evaluation

[`reference_metrics.json`](reference_metrics.json) is the machine-readable
Milestone 4 benchmark generated from commit `eeeda1e` with the official 2023 and
2024 NEA historical PSI datasets.

The large raw CSVs, row-level predictions, and serialized model remain ignored.
Their SHA-256 fingerprints and every evaluation boundary are preserved in the
report so another run can verify that it used the same inputs.
